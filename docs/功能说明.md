# 🔥 热点监控工具 (Yupi Hot Monitor / HotPulse)

> 一款自动发现热点、智能识别真假内容、实时推送通知的 AI 工具

## 📋 项目概述

作为 AI 编程博主，需要第一时间获取热点信息（如 AI 大模型更新），本工具可以：

- **关键词监控**：按词定时/手动扫描多源，AI 过滤后入库并通知
- **平台发现**：无需关键词，直接拉 GitHub / 微博 / HN / B 站 / HF 等纯榜单，并做 AI 洞察
- **全网搜索**：输入任意词即时搜 10 源，可选单平台、时间窗、指标排序后入库
- **热点雷达**：统一查看、筛选、导出已入库热点

## 🎯 核心功能

### 1. 关键词监控

- 添加 / 编辑 / 删除 / 激活·暂停监控词
- 分类、模板一键导入、JSON 导入导出
- 定时扫描 + 顶栏「立即扫描」
- AI：查询扩展、真假识别、相关性、重要性、摘要
- 高优先级：站内通知、邮件、Webhook（钉钉/飞书）

### 2. 平台发现（无关键词榜单）

与「监控词 + 搜索」并列的第三条主线：

| 能力 | 说明 |
|------|------|
| **纯榜单** | 不输入关键词，按平台 API 拉 Trending / 热搜 / 热门 |
| **5 个平台** | GitHub、微博热搜、Hacker News、Bilibili、Hugging Face |
| **时间窗** | 今天 / 近 7 天 / 近 30 天（因平台能力而异） |
| **指标排序** | Star、播放量、点赞、趋势分等（随平台变化） |
| **Top 5 AI** | 每次刷新对榜单前 5 条做 OpenRouter 分析 |
| **榜单快照** | 每次非缓存刷新写入 `PlatformSnapshot`，供历史对比 |
| **快照趋势图** | 近 7 天内每次刷新的柱状条（柱高 = 当次条数） |
| **AI 热点洞察** | 规则抽词 + 跨快照聚合 + AI 主题/总结/周对比（今日/7天/30天） |
| **一键入库** | 将当前榜单批量写入热点库（`discovery:平台:时间窗` 作关联词） |

> Google / Bing 等搜索引擎**没有可靠「榜单 + 浏览量」**，故未纳入发现模式（搜索 Tab 仍可用）。

### 3. 热点收集与雷达

- 默认定时扫描间隔可在设置中配置（5～1440 分钟）
- **10 数据源**并行聚合（见下表）
- 仪表盘：统计卡片、**近 7 天入库趋势**（按日聚合，与发现页快照趋势不同）
- 筛选、排序、分页、详情抽屉、Markdown 报告导出

### 4. 全网即时搜索

- 与定时监控共用 `aggregateSearch`（10 源 + 账号检测）
- **搜索增强**：可选单平台、时间范围、指标排序（`SearchOptionsPanel`）
- 结果 AI 分析后支持单条 / 全部入库

### 5. 通知系统

- WebSocket 实时推送 + 站内通知中心
- 邮件（高/紧急即时 + 可选每日 08:00 日报）
- Webhook（钉钉 / 飞书 / 通用 JSON）

## 🛠️ 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | React 19 + Vite 7 + React Router 7 + Tailwind CSS 4 | 五 Tab + 详情路由 |
| 后端 | Express 5 + Socket.io 4 | REST + 实时 |
| 数据库 | SQLite + Prisma 6 | Keyword / Hotspot / Notification / Setting / **PlatformSnapshot** / **DiscoveryInsight** |
| AI | OpenRouter → DeepSeek V3.2 | 监控分析、发现 Top5、洞察生成 |
| 定时任务 | node-cron | 扫描间隔、每日日报 |
| 邮件 | Nodemailer | SMTP（`.env`） |

## ⚠️ 已知限制

1. **SMTP**：账号密码在 `server/.env`；设置 Tab 只控制开关与 Webhook URL。  
2. **发现页快照趋势**：一根柱子 = **一次刷新**，不是「每天一根」；同一天多次刷新日期标签相同（如 `06-02`）。  
3. **发现洞察**：依赖至少 2 次快照才有意义；首次使用需多点几次「刷新榜单」。  
4. **Google / 部分 HTML 源**：可能空结果或限流，可在设置中关闭。  
5. **单用户**：无登录；SQLite 本地库。  
6. **生产部署**：见 [DEPLOY.md](./DEPLOY.md)。

## ⚙️ 配置说明

```env
# OpenRouter AI（必需）
OPENROUTER_API_KEY=your_openrouter_key

# Twitter API（可选）
TWITTER_API_KEY=your_twitter_api_key

# GitHub（可选，提高限额）
GITHUB_TOKEN=ghp_xxx

# 邮件通知（可选）
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your_email
SMTP_PASS=your_password
NOTIFY_EMAIL=receive@example.com

DATABASE_URL=file:./dev.db
CLIENT_URL=http://localhost:5173
PORT=3001
```

## 🚀 快速开始

```bash
# 项目根目录
npm run install:all
cp server/.env.example server/.env   # 填入 OPENROUTER_API_KEY
npm run db:push
npm run demo          # 可选：演示关键词 + 热点
npm run dev           # 同时启动 :3001 + :5173
```

浏览器打开 http://localhost:5173 。详细步骤见 [LOCAL_SETUP.md](./LOCAL_SETUP.md)，操作见 [使用说明.md](./使用说明.md)。
